# Deloitte Australia Data Analytics Job Simulation

Completed the Deloitte Australia Data Analytics Job Simulation on Forage in September 2026.

## Overview

This simulation involved two data analytics tasks focused on operational telemetry analysis and workplace equality analysis.

## 1. Tableau Data Analysis

Analyzed Daikibo's telemetry data across four factory locations to identify patterns in machine downtime.

Key tasks:

* Created a calculated `Unhealthy` measure to quantify potential machine downtime.
* Analyzed downtime by factory and device type.
* Developed interactive Tableau worksheets and a dashboard.
* Used factory-level filtering to investigate device-specific downtime patterns.
* Identified the factory with the highest downtime.

## 2. Excel Equality Analysis

Analyzed employee equality scores across factories and job roles.

Key tasks:

* Classified equality scores into Fair, Unfair and Highly Discriminative categories.
* Applied conditional classification logic in Excel.
* Used the resulting categories to support interpretation of workplace equality data.
